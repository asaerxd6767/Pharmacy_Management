# Pharmacy Management System 💊

A modern, cross-platform solution designed to replace manual pharmacy record-keeping with an automated digital workflow. Engineered for Web, iOS, and Android, this system streamlines inventory management, patient administration, billing, and reporting to enhance operational efficiency and reduce medication errors.

---

## ✨ Key Features

* **📦 Inventory Tracking:** Real-time stock levels, low-stock alerts, and batch/expiry monitoring.
* **📋 Patient Records:** Centralized management of patient profiles, prescription histories, and contact info.
* **🧾 Billing & POS:** Quick transaction processing, automated price calculations, and receipt generation.
* **📊 Reporting & Analytics:** Visual insights on daily sales trends, fast-moving items, and inventory valuation.
* **📱 Cross-Platform UI:** Fully responsive interface optimized for mobile screens and web browsers.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your local machine:
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (latest stable version)
* Target platform toolchains:
  * **Web:** Google Chrome or any modern browser
  * **Android:** Android Studio & Android SDK
  * **iOS:** macOS with Xcode installed

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/pharmacy-management-system.git](https://github.com/your-username/pharmacy-management-system.git)
   cd pharmacy-management-system

```

2. **Install dependencies:**
```bash
flutter pub get

```


3. **Run the application:**
* **Web:**
```bash
flutter run -d chrome

```


* **Mobile (Android/iOS):**
```bash
flutter run

```
